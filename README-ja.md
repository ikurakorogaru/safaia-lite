# Safaia Lite 1.2.0 — 導入と変更内容

指定されたSafaia 1.1.0を逆コンパイルして復元し、動作時のCPU負荷と一時メモリ割り当てを減らした版です。
Minecraft 26.2／Fabric／Java 25向けです。元のMODと同じID `safaia00` を使います。

## 入っているもの

- `safaia-1.2.0-lite.jar`: ゲームに導入する軽量化版。
- `safaia-1.1.0-restored-source.zip`: 復元ソース、元リソース、手直し前の逆コンパイル結果、ビルド設定。
- `safaia-1.2.0-lite-source.zip`: 軽量化版ソース、ビルド設定、テスト、検証結果。

## 導入

1. Minecraftを終了します。
2. 利用するMinecraftプロファイルの `mods` フォルダーから旧SafaiaのJARを別の場所へ移します。同じMOD IDのJARは同時に入れないでください。
3. `safaia-1.2.0-lite.jar` を `mods` に入れます。
4. Minecraft 26.2、Fabric Loader 0.19.3以上、Java 25以上、Fabric APIを使用して起動します。ビルドに使用したAPIは0.159.0+26.2です。
5. F8、または `/safaia` で画面を開きます。

ゲームの既存インストール・MODフォルダー・ワールド・画質設定は、この作業では変更していません。

## 軽量プリセット

F8 →「状態」→「軽量プリセットを適用」。または `/safaia preset lite`。
起動しただけでは画質を変えません。内部の負荷削減は導入時から有効です。

| 設定 | プリセット適用後 |
|---|---|
| 描画距離 | 最大8チャンク。すでに低い場合は維持 |
| シミュレーション距離 | 最大5チャンク。すでに低い場合は維持 |
| エンティティ描画距離の倍率 | 最大50%。すでに低い場合は維持 |
| 雲・エンティティの影・滑らかな陰影 | OFF |
| パーティクル | 最少 |
| バイオームの色の混合 | 0 |
| 天候の描画半径 | 3（26.2で有効な最小値） |
| チャンクのフェードイン時間 | 0 |

「画質設定を元に戻す」、または `/safaia preset restore` で、変更した項目をプリセット適用前に戻します。
描画距離などを下げるため、遠景や表示されるエフェクトは変わります。マルチプレイでは、サーバー側のシミュレーション距離は変更しません。

元の値はゲームの `config/safaia-video-backup.properties` に保存します。繰り返し適用しても上書きしません。
復元後も `config/safaia-video-last-restored.properties` に回復用コピーを残します。
次にプリセットを適用すると、その時点の設定を新しく保存します。
バックアップを作れない場合はプリセットを適用しません。Minecraft自身の設定保存エラーはゲームのログに出ます。

## 内部で軽くした箇所

| 箇所 | 元版 | Lite版 |
|---|---|---|
| 遠方チャンク座標 | 操作ごとにリストと最大892個の小配列を生成 | 共有の整数配列を再利用 |
| 画面のチャンク調査 | 約1秒ごとに最大1,089件を一括調査 | チャンクタブでのみ、1tick最大64件に分散 |
| 調査周期 | 20tick | 40tick。半径16の初回完了は18tick |
| 調査用配列 | 調査のたびに新規確保 | 2つの配列を交互に再利用 |
| 統計表示・ボタンラベル | 描画ごとに文字列の作成や幅計算 | 統計更新時・ラベル変更時に再計算 |
| Safaia専用キャッシュ | 上限なし、整理時に全件確認 | 最大256件、古い順に整理、空なら内部マップを保持しない |
| 時間判定 | 壁時計 | 時刻の手動変更に影響されない経過時間 |
| 未使用コード | 登録されていない初期化クラス、空Mixin、ダミー型など | 実行JARから除外 |

元版のキャッシュはSafaia専用であり、Minecraft全体のキャッシュではありません。元JAR内にはこのキャッシュへデータを登録する呼び出しがありませんでした。
したがってキャッシュ整理だけでゲーム全体のメモリが大きく減るわけではありません。
通常プレイの描画負荷を下げる主な追加機能は、上記の軽量プリセットです。

チャンク画面の表示は、分散して調べた近況です。各セルが同じ瞬間の状態を示すものではありません。
更新周期を延ばした分、表示には遅れがあります。移動・ワールド切替時は調査をやり直します。
手動の `/safaia chunks` は即時結果の互換性を維持するため一括調査です。

## 残した操作

`/safaiatest`、`/safaia gui`、`/safaia optimize on|off|status`、`/safaia memory`、
`/safaia memory optimize`、`/safaia memory clear`、`/safaia chunks`、
`/safaia chunksdrop <x> <z>`、`/safaia chunksunload [1～100]`。

元からある遠方チャンク解放は手動操作です。自動でのチャンク削除や強制GCは追加していません。
半径8チャンクの保護範囲は維持しています。チャンク解放では地形表示が欠け、再接続が必要になる場合があります。
これは元からある機能の制約で、ワールド保存データを削除する操作ではありません。

## 確認できたこと・未確認のこと

- 復元版・Lite版ともJava 25でMinecraft 26.2とFabricの実ライブラリに対してコンパイル成功。
- キャッシュの期限境界、LRU、上限、同時アクセス、時間カウンターの周回を検証。
- 半径0～16でチャンクの保護範囲、重複なし、元と同じ順序、セルの位置・件数を検証。
- 毎tickの調査上限、40tick周期、移動・ワールド切替・切断時の破棄を検証。
- バックアップの読み書き、再適用時の保全、復元後の保持、保存失敗を検証。
- 元のJARを直接読み込み、座標列の比較用コードが実際の元版と一致することも確認。
- 遠方座標の生成・走査単体を10,000回計測。準備運転後の一時割り当ては元版36,432 B/回、Lite版0 B/回。

この数値は座標列の処理単体です。チャンクを解放する処理全体・MOD全体・Minecraft全体のメモリ消費ではありません。
Lite版も初回に共有配列を作ります。計測値はPC・JVM条件に依存します。
実際のMinecraftの起動、画面表示、他MODとの組合せ、設定変更のゲーム内反映、FPSは未検証です。
FPSの向上率や総メモリ使用量の削減率は保証・計測していません。

JARの容量は元版61,714 Bに対しLite版65,747 Bです。設定復元機能などを追加したため少し増えています。
今回はダウンロード容量ではなく動作時の負荷を優先し、元のロゴ画像は維持しました。

## ソースからビルド

ZIPを展開し、JDK 25を使って `gradlew.bat build`（Windows）または `./gradlew build`。
通常のGradle経由はビルド設定を用意したのみで、この作業では実行していません。
Gradle 9.5.1、Loom 1.17.20、Minecraft 26.2、Loader 0.19.3、API 0.159.0+26.2を指定しています。

このPCで実行して成功したオフラインビルド（PowerShell）:

```powershell
.\build-local.ps1 -JdkHome 'C:\Program Files\Java\jdk-25.0.4.1'
```

既存Gradleキャッシュから依存ライブラリを参照し、コンパイル、内部テスト、JAR作成を行います。
出力先は `build/manual/`。別PCで必要なキャッシュがない場合はGradle経由で依存を取得してください。
ゲーム本体、Fabric API、JDKはソースZIPやMODのJARには同梱していません。
